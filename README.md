# ESP32-S3_Horloge_RadioStream

Version finale de ce projet, Le montage est destiné à être placé sur le dock d'une ancienne enceinte active. Je trouvais dommage que l'affichage était inactif à l'arrêt, j'ai donc ressorti le sketch d'une ancienne horloge qui occupera l'écran hors écoute radio stream. La bascule horloge - radio se fait par touch 2 doigts sur l'écran et inversement. Pour attaquer l'enceinte par une entrée line je remplace les modules MAX par un PCM5102.
